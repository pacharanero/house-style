# New Repository Templates

Copy only the files that fit the project. These are optional community-health templates, not mandatory boilerplate.

- [`CONTRIBUTING.md`](CONTRIBUTING.md) - contribution expectations for collaborative repositories.
- [`SECURITY.md`](SECURITY.md) - private vulnerability-reporting policy.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) - short Contributor Covenant pointer.
- [`pull-request-template.md`](pull-request-template.md) - GitHub pull-request checklist; copy to `.github/pull_request_template.md`.
- [`bug-report.md`](bug-report.md) - GitHub issue form; copy to `.github/ISSUE_TEMPLATE/bug-report.md`.
- [`feature-request.md`](feature-request.md) - GitHub issue form; copy to `.github/ISSUE_TEMPLATE/feature-request.md`.
- [`editorconfig`](editorconfig) - neutral editor defaults; copy to `.editorconfig`.
- [`markdownlint.json`](markdownlint.json) - Markdown lint configuration; copy to `.markdownlint.json`.
- [`gitignore`](gitignore) - minimal ignored-secret and local-file baseline; copy to `.gitignore` and add only relevant stack patterns.

Replace every placeholder before publishing. Do not add any of these files to a private or solo repository merely because they are available here.
