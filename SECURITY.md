# Security Policy

## Reporting A Vulnerability

Do not report suspected vulnerabilities through public issues.

Use GitHub's private vulnerability reporting for `pacharanero/house-style` when it is enabled. Until then, contact the maintainer privately through the repository owner's GitHub profile.

Include a description of the issue and impact, affected versions or commit hashes, safe reproduction steps, and any suggested mitigation. Redact credentials and sensitive data.

## Scope

This policy covers this repository and its published examples. Report upstream dependency vulnerabilities to the relevant maintainer and notify this project privately if they affect the repository.

## Disclosure

We use coordinated disclosure. After a fix is available, we will publish an appropriate advisory or release note and credit the reporter if they agree.
